## What this project is about?
### It's an aesthetic cool table calendar. The model has got 3 rings to mark the day, date, & month. You Just need to write the short forms of month like Jan, Feb, & Mar etc. Same way you need to write short forms of day's like Mon, Tue, & Wed etc. Do not forget the dates. I will be using a fine tip black marker to write this.
